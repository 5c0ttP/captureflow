Troubleshooting

Resolve common CaptureFlow problems.

Work through the relevant steps below before opening a support request.

When requesting help: Fictional screenshots or private data should never be included in public reports. Describe the problem without attaching sensitive images.

A capture permission is denied

  1. Open chrome://extensions and select CaptureFlow’s details.
  2. Review site-access permissions and allow access for the page you intend to capture.
  3. Reload the target page and start the capture again.

A Chrome page cannot be captured

Chrome blocks extensions from capturing protected pages such as chrome:// pages, the Chrome Web Store, and some browser-controlled screens. Open an ordinary website and try again.

The side panel cannot capture after switching tabs

  1. Grant CaptureFlow’s optional website access when prompted.
  2. If you declined it, open CaptureFlow’s extension details and update site access.
  3. Return to the website, reload it, and retry from the side panel.

A full-page capture is incomplete

  1. Wait for the page to finish loading.
  2. Close menus, sticky overlays, or dialogs that obscure the page.
  3. Avoid scrolling or switching tabs while CaptureFlow stitches the page.
  4. Retry after reloading if the page changes content while scrolling.

An image will not import

Confirm the file is PNG, JPEG, or WebP, is not empty or corrupted, and is within CaptureFlow’s supported file-size limit. Export unusual formats to PNG or JPEG before importing.

A download or ZIP export does not appear

  1. Check Chrome’s Downloads page for an error or blocked download.
  2. Confirm Chrome is allowed to download files to the configured location.
  3. Ensure the destination has sufficient free space, then retry.

The Windows folder is disconnected

  1. Open CaptureFlow Settings.
  2. Reconnect the optional Windows backup folder and approve read/write access.
  3. If the folder was moved or renamed, select its new location.
  4. Retry any entries marked as pending or failed.

Library data is missing after uninstalling or clearing storage

CaptureFlow’s working library is stored in the current Chrome profile. Uninstalling the extension, clearing its data, or resetting the profile removes that storage. Downloads and folder copies cannot currently restore the library.
