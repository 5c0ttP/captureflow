How support works

CaptureFlow uses the Support section on its Chrome Web Store listing. The direct listing link will be added after CaptureFlow is published.

  1. Open CaptureFlow in the Chrome Web Store.
  2. Open the listing’s Support section and choose the appropriate request type.
  3. Describe the behavior without attaching private captures or imported images.
