Frequently asked questions

How CaptureFlow handles your images and data.

CaptureFlow is designed as a local working library. These answers explain what is saved, what leaves the extension, and what cannot be restored.

Where does CaptureFlow store my library?
The working image library, metadata, and settings are stored in IndexedDB inside your current Chrome profile. CaptureFlow has no backend, cloud library, or account system.
Are screenshots or imported images uploaded?
No. Capturing, importing, stitching, cropping, annotation, blur, pixelation, thumbnails, and duplicate hashing run locally using browser capabilities. CaptureFlow does not transmit your images to the developer or third parties.
Which image files can I import?
CaptureFlow accepts local PNG, JPEG, and WebP images within its supported file-size limit. The selected image and its basic file information are stored locally in the working library.
Does editing replace my original image?
No. CaptureFlow keeps the original and stores an edited version only when visual edits are saved. You can view or download the original separately.
Are downloads and ZIP exports backups?
They are one-way copies. CaptureFlow can download individual images and create ZIP exports, but it cannot currently restore or import a CaptureFlow library from those files.
What does the optional Windows folder do?
When enabled, CaptureFlow can write local PNG, JSON, and Markdown copies to a folder you choose. These copies do not replace the IndexedDB working library and cannot restore it.
Why might a Windows folder need to be reconnected?
Chrome controls access to the selected folder. Browser restarts, permission changes, profile changes, or moving the folder may require you to reconnect or grant permission again.
What happens if I uninstall CaptureFlow?
Uninstalling the extension removes its Chrome-profile storage. CaptureFlow has no cloud copy and cannot recover that library. Files previously downloaded or copied to a Windows folder remain wherever you saved them.
Can support recover missing captures?
No. Support has no remote access to your local Chrome profile or image library. If Chrome storage was cleared, the profile was reset, or the extension was uninstalled, the working library cannot be recovered by CaptureFlow.
