CaptureFlow Privacy Policy

Effective date: July 22, 2026

CaptureFlow is a Chrome extension for capturing, importing, annotating, organizing, and retrieving images locally. Privacy is part of its core design.

Information CaptureFlow handles

When you choose to capture a page, CaptureFlow handles the screenshot image, page and tab titles, page URL and domain, capture date, and browser dimensions. When you import an image, CaptureFlow handles the local PNG, JPEG, or WebP file you selected and its filename, dimensions, and file type. CaptureFlow also handles the notes, tags, project names, favorites, and visual edits you add.

If you choose a Windows folder for local copies, Chrome provides CaptureFlow with a permission-scoped directory handle and folder name. CaptureFlow does not learn the folder's full system path.

How information is used

This information is used only to provide CaptureFlow's user-facing capture, import, editor, search, organization, download, ZIP export, and optional local-folder-copy features. Image capture, stitching, cropping, annotation, blur, pixelation, thumbnail display, and duplicate hashing run locally using browser image and canvas capabilities.

Storage, transmission, and sharing

  • The working image library, metadata, and settings are stored locally in the current Chrome profile using IndexedDB.
  • CaptureFlow has no backend, account system, analytics, advertising, cloud upload, or remote image processing.
  • CaptureFlow does not transmit screenshots, imported images, browsing information, notes, tags, settings, edits, or folder handles to the developer or third parties.
  • CaptureFlow does not sell user data or use it for advertising, unrelated purposes, lending, or credit decisions.
  • Files leave IndexedDB only through a download, ZIP export, clipboard action, or optional local folder copy that you explicitly request. These actions keep the data on your device unless you later choose to share it yourself.

Website access

CaptureFlow accesses ordinary website content only when needed for a screenshot you initiate. Optional access to all websites enables user-initiated captures after you switch tabs while using the side panel. You may decline or remove that optional access. Chrome does not allow extensions to capture protected pages such as chrome:// pages.

Downloads and optional Windows folder copies

Individual downloads, ZIP exports, and optional PNG, JSON, and Markdown folder copies are one-way copies. They do not replace the IndexedDB working library, and CaptureFlow cannot currently restore or import a library from them. Deleting a downloaded copy does not delete the CaptureFlow record.

Retention and deletion

CaptureFlow data remains in the current Chrome profile until you delete it, clear CaptureFlow's local data, clear browser extension data, reset the profile, or uninstall the extension. Items in CaptureFlow's Trash remain stored until permanently deleted. Files you downloaded or copied to a folder remain there until you delete them separately.

Security and Limited Use

CaptureFlow does not execute remotely hosted code. The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

If CaptureFlow's data practices change, this policy, the in-product disclosures, and the Chrome Web Store privacy disclosures will be updated before those changes are released.

Support

For privacy questions, bug reports, or feature requests, use the Support section on CaptureFlow's Chrome Web Store listing or review the CaptureFlow support guidance. Support requests do not automatically include your screenshots, imported images, notes, or library data.
