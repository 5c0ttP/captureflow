# Portfolio review guide

CaptureFlow's complete implementation is private, but this showcase is organized to make the product and engineering work easy to evaluate.

## Suggested five-minute review

1. Watch the animated product walkthrough in the main README.
2. Review the feature set and local-first architecture diagram.
3. Read the [engineering decisions](engineering-decisions.md) for privacy, storage, permission, and export tradeoffs.
4. Inspect the small representative code samples for domain modeling and deterministic collection queries.
5. Review the public milestone, issues, merged pull requests, and tagged releases for project-management history.

## What the showcase demonstrates

- Product thinking across capture, editing, organization, privacy, and recovery
- Chrome extension architecture and permission-aware UX
- Local persistence and clear data-ownership boundaries
- Automated testing and reproducible release practices
- Written communication through decision records and issue-driven planning

## Intentionally private

The production application, full test suite, capture and image-processing algorithms, database implementation, store packaging scripts, release credentials, and future feature implementation remain in the private repository.
